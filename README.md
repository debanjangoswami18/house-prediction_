House Price Prediction 🏠

 🚀 Live  Demo

[🏠 Try House Price Prediction](https://house-prediction-cneguby45qtxbtkg3dwgps.streamlit.app/)

This is a Machine Learning project that predicts the estimated price of a house based on factors like house area, number of bedrooms, bathrooms, and house age.
Tech Stack

- Python
- Pandas
- Machine Learning
- Joblib
- Streamlit

How it works
The user enters the house details, and the ML model predicts the estimated house price. The model is used through a simple Streamlit web interface.

My Experience
I built this project to practice Machine Learning and learn about data handling, model training, and using a trained model with Streamlit.

Projects Files

app.py – Streamlit application
house_price.py – Machine Learning model training
house_data.csv – Dataset
house_price_model.pkl – Trained ML model
